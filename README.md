# Scena: σενάριο & θεατρικό

Ένας επεξεργαστής σεναρίου και θεατρικού έργου, για προσωπική χρήση, που δουλεύει χωρίς internet.
Ο ίδιος κώδικας τρέχει ως πρόγραμμα στα Windows (Electron) και ως εφαρμογή στο tablet (PWA).

## Windows

Εγκατάσταση με το «Εγκατάσταση.bat» του πακέτου (όπως το Race HQ). Από την 1.1 ενημερώνεται μόνο του:
ελέγχει το `update/manifest.json` αυτού του repo, κατεβάζει μόνο ό,τι άλλαξε, και ζητά επανεκκίνηση.
Αν μια νέα έκδοση δεν ξεκινήσει 3 φορές, ανοίγει αυτόματα η προηγούμενη.

Νέα έκδοση: αλλαγή `version` στο `package.json` → `node tools/make-manifest.js "τι άλλαξε"` → commit & push.

* Τα έργα αποθηκεύονται ως αρχεία `.scena` στον φάκελο **Έγγραφα › Scena**,
  με το όνομα του έργου. Το κουμπί «Φάκελος» στη βιβλιοθήκη τον ανοίγει.
* Κάθε μέρα που ανοίγεις ένα έργο, κρατιέται αντίγραφο της προηγούμενης εκδοχής στο `Έγγραφα › Scena › .αντίγραφα`.
* Η εξαγωγή σε PDF γίνεται απευθείας σε αρχείο (Ctrl+P).
* Ορθογραφικός έλεγχος σε ελληνικά και αγγλικά (δεξί κλικ για προτάσεις).

## Tablet (Android)

Με GitHub Pages ενεργό σε αυτό το repo, η εφαρμογή είναι στο https://harrytsir.github.io/scena/app/
και ενημερώνεται μόνη της σε κάθε push.

Στο tablet άνοιξε τη διεύθυνση στον Chrome και πάτα **⋮ › Εγκατάσταση εφαρμογής**
(ή «Προσθήκη στην αρχική οθόνη»). Από εκεί και πέρα ανοίγει σαν κανονική εφαρμογή και
**δουλεύει και χωρίς internet**. Τα έργα μένουν αποθηκευμένα στη συσκευή.

### Μεταφορά ανάμεσα σε υπολογιστή και tablet
**Εξαγωγή › Αρχείο Scena (.scena)** στη μία συσκευή και μετά **Εισαγωγή αρχείου…** στην άλλη.
Αν το έργο υπάρχει ήδη, σε ρωτάει αν θέλεις να το αντικαταστήσεις ή να το κρατήσεις ως αντίγραφο.
(Ο αυτόματος συγχρονισμός μέσω του server σου είναι το λογικό επόμενο βήμα.)

## Τι κάνει

| | |
|---|---|
| **Μορφές** | Σενάριο ταινίας (Σκηνή, Δράση, Χαρακτήρας, Παρένθεση, Διάλογος, Μετάβαση, Πλάνο) και θεατρικό (Πράξη, Σκηνή, Σκηνική οδηγία, Χαρακτήρας, Παρένθεση, Διάλογος, Μετάβαση) |
| **Ροή γραφής** | Enter/Tab όπως στο Celtx/Final Draft, Ctrl+1…7, κουμπιά τύπου στο κάτω μέρος για το tablet |
| **Ελληνικά** | Κεφαλαία χωρίς τόνους σε σκηνές/ονόματα (ΑΪ όπου χρειάζεται), αναζήτηση χωρίς τόνους |
| **Προτάσεις** | Χαρακτήρες, ΕΣΩΤ./ΕΞΩΤ., τοποθεσίες, ώρα, μεταβάσεις, «ΠΡΑΞΗ ΔΕΥΤΕΡΗ», «ΣΚΗΝΗ 3» |
| **Σελίδες** | Τυπική σελιδοποίηση (Courier 12, A4 ή Letter), (ΣΥΝΕΧΙΖΕΙ)/(ΣΥΝ.), νέα σελίδα σε κάθε πράξη |
| **Οργάνωση** | Λίστα σκηνών, χαρακτήρες με αριθμό ατακών, κάρτες με σύνοψη και αναδιάταξη σκηνών |
| **Εξαγωγή** | PDF με σελίδα τίτλου (και σελίδα «Πρόσωπα» στο θεατρικό), Word με στυλ, Final Draft, Fountain |
| **Εισαγωγή** | PDF (π.χ. από Celtx), Word, Final Draft, Fountain, απλό κείμενο, θεατρικά γραμμένα «ΟΝΟΜΑ: ατάκα» |
| **Διασκευή** | Ρυθμίσεις › «Αντίγραφο ως θεατρικό» (ή ως σενάριο): νέο έργο, το πρωτότυπο μένει ανέγγιχτο |
| **Λοιπά** | Αναίρεση, αναζήτηση/αντικατάσταση, αρίθμηση σκηνών, νυχτερινή λειτουργία, αυτόματη αποθήκευση |

## Αρχεία

```
app/         η εφαρμογή (HTML/CSS/JS, χωρίς εξαρτήσεις)
  app.js       επεξεργαστής, βιβλιοθήκη, κάρτες, διάλογοι
  layout.js    μορφές στοιχείων, ελληνικά κεφαλαία, σελιδοποίηση, PDF
  formats.js   εισαγωγή/εξαγωγή (Fountain, FDX, Word, PDF)
  store.js     αποθήκευση (αρχεία στα Windows, συσκευή στο tablet)
  vendor/pdfjs Mozilla pdf.js (για ανάγνωση PDF), Apache-2.0
  fonts/       Liberation Mono (ίδια μετρικά με Courier New), SIL OFL
electron/    το κέλυφος για τα Windows
```
